# 🚌 Campus Bus Route Optimizer

A Python-based campus bus route optimization project using Streamlit, NetworkX, NumPy, and Matplotlib.

## Features

- Student density input
- Campus route network
- Shortest path optimization
- Network matrix
- Route visualization
- Distance calculation
- Estimated travel time

## Technologies Used

- Python
- Streamlit
- NetworkX
- NumPy
- Matplotlib

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
